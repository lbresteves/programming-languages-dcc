Divide uma lista em 2 metades:

fun halve nil = (nil, nil)
    | halve [e] = ([e], nil)
    | halve (a::b::t) = 
        let
            val(L0, L1) = halve t
        in
            (a::L0, b::L1)
        end

mergeeia 2 listas que, caso as duas estejam ordenadas, a lista mergeeada vai continuar ordenada:
fun merge (nil, L1) = L1
    | merge(L0, nil) = L0
    | merge (x::xs, y:ys) = 
        if x < y
        then
            x :: merge(xs,y::ys)
        else
            y :: merge(x::xs, ys)

O mergesort (John von Neumann) divide a lista em 2 metades e ordena

fun msort nil = nil

Quick sort

fun partition (pivot, nil) = (nil, nil)
    |partition (pivot, first::others) = 
    let
        val (smalls, bigs) = partition (pivot, others)
    in
        if first < pivot then (first::smalls, bigs) else (smalls, first::bigs)
    end

fun qsort nil = nil
    | qsort (first::rest) = 
    let
        val (smalls, bigs) = partition(first,rest)
    in
        qsort smalls @ first :: (qsort bigs) 
    end


Sublista de maior soma:
O algoritmo de Kadane é uma técnica eficiente de programação dinâmica usada para encontrar a soma máxima de um subarray contíguo dentro de uma lista de números inteiros (que podem ser positivos ou negativos) em tempo linear O(n)

fun max(x,y) = if x > y then x else y

fun kadane nil _ glob = glob
    | kadane (h::t) curr glob = 
    let
        val next_curr = mas(h, curr + h)
        val next_glob = max(glob, next_curr)

    in
        kadane t next_curr next_glob
    end

ex.:
- kadane [ ~2, 1 ~3, 4, ~1, 2, 1, ~5 ,4]

find_max_subarray (h::t) = kadane t h h
