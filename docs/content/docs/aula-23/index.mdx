imagine que queremos somar

```
sum([],0).
sum([Head|Tail],X) :- sum(Tail,TailSum), X is Head + TailSum.
```

> sum([1,2,3], N)

> N = 6.

`sum([H|T], N) :- sum(T, NN), N is NN + H.`
esse gera erro por conta da variavel nao definida.
Esse nao é de cauda rasa. Pra transformar em cauda rasa:

```
sum_tl([], Acc, Acc).
sum_tl([H|T], Acc, X) :- NovoAcc is Acc + H, sum_tl(T, NovoAcc, X).

```

sum_tl([1,2,3,4], 10, X)

é de cauda rasa, pois a ultima coisa que ele faz é recursivo

algoritmo euclidiano:

```
gcd(N1, N2, GCD) :- N1 < N2, euclid(N2, N1, GCD).

euclid(N, 0, N).
```

Progrma NP Completo: da pra resolver em tempo polinomial num maquina nao deterministica, e se resolve 1, resolve todos.

um dos problemas mais famosos np-completo é o de subset sum.
em prolog é simples de resolver:

```
subsum(L, N, S) :- subset(L, S), sum_tl(S, 0, N).
```

como pegar as permutações de uma lista?

```
perm([], []).
perm(List, [H|Perm]) :- select(H, List, Rest), perm(Rest, Perm).
```

Problema das 8 rainhas:

```
nocheck(_, []).
nocheck(X/Y, [X1/Y1 | Rest]) :-
  X =\= X1,
  Y =\= Y1,
  abs(Y1-Y) =\= abs(X1-X),
  nocheck(X/Y, Rest).

legal([]).
legal([X/Y | Rest]) :-
  legal(Rest),
  member(X,[1,2,3,4,5,6,7,8]),
  member(Y,[1,2,3,4,5,6,7,8]),
  nocheck(X/Y, Rest).
```

é preciso fixar o X:

```
eightqueens(L) :-
  L = [1/_,2/_,3/_,4/_,5/_,6/_,7/_,8/_],legal(L)
```

```
legal([]).
legal([X/Y | Rest]) :-
  member(Y,[1,2,3,4,5,6,7,8]),
  nocheck(X/Y, Rest),
  legal(Rest).
```
